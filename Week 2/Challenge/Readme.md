# Desktop File Organizer Automation

## Overview
This project automates the task of organizing files inside a folder. It sorts files into categories such as Images, PDFs, Documents, Videos, Archives, and Others. The script supports preview mode, undo operations, and custom file categories through a configuration file.

This project was created as part of the AI for Bharat Week 2 Challenge: “Lazy Automation”.

## Problem Statement
I often end up with multiple different file types inside a single folder. Manually organizing these files into subfolders is repetitive and time-consuming. This project automates the entire process.

## Features
- Automatically organizes files based on their extension
- Preview mode to see changes before applying
- Undo support to revert the last operation
- Handles duplicate filenames
- Customizable file categories using `file_config.json`
- Progress bar for better visibility
